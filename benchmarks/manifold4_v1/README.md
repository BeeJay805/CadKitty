# manifold4_v1 — the complex-part author A/B corpus (frozen 2026-07-21)

ONE brief, deliberately hard: a display-scale 4-into-1 exhaust manifold. Founder-directed
(2026-07-21) as the "single plan, three authors" experiment — the same extremely detailed
plan authored by Fable, Opus, and Sonnet arms so author capability is the only variable.

Provenance: the founder-grade prompt (dimensionally coherent: 19 mm ports == runner ID,
collector area ~ 4 runners) was expanded ONCE into the DesignBrief by `research_brief` on
**claude-fable-5** (subscription, $0) and frozen verbatim — planner variance is out of the
measurement, exactly the local_breadth_v1 discipline. `validate_brief` warnings: none; the
prose envelope parses as (150, 120, 180).

Why this part: it stresses the measured weak classes on purpose — swept hollow runner tubes
(thin-wall class in its native habitat), a 4-into-1 loft merge (relational geometry), two
counted bolt patterns + 4 counted runners (feature-presence G3), and envelope discipline.

Arms run `scripts/bench_local_arm.py --briefs benchmarks/manifold4_v1/briefs.json` with
`FORGE_PROVIDER_CODER/REPAIR=claude_code`, `FORGE_AUTHOR_MODEL={fable|opus|sonnet}`,
FEATURE_PRESENCE=1 (v2 gate), 32B critic, max_iterations=6, n=1, sequential (window + critic
swap discipline). Ship = stopped_reason "accepted". Results gitignored; the corpus is the
only committed artifact. SHA-pinned in MANIFEST.sha256; a corpus change is a new version
dir, never an edit.
